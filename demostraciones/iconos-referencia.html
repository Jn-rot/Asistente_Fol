Estilos de botón de ícono (icon buttons)3 variantes
Ghost / sutil
Fondo transparente, se resalta solo al pasar el mouse. Para acciones secundarias.
Outline con acento
Borde y fondo tenue del color de marca. Para la acción principal secundaria (ej. "Nuevo").
Filled / sólido
Fondo sólido del color de marca. Para la acción principal de la pantalla (ej. "Enviar").

Estos son SVG dibujados a mano — sin librería externa. Si quieres el mismo estilo con más variedad, estas librerías gratuitas tienen íconos muy parecidos:
lucide.dev · heroicons.com · feathericons.com · phosphoricons.com · tabler.io/icons

Para usar cualquiera de ellos: buscas el ícono por nombre, copias el código <svg>, y lo pegas donde lo necesites — o instalas el paquete npm si trabajas con React/Vue.
